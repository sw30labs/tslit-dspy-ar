ABOUT TSLIT-DSPy

Time-Shift LLM Integrity Testing with DSPy-Powered Analysis.

What it does

Detects dormant adversarial backdoors in open-weight AI models (Qwen, DeepSeek, MiniMax) across three threat classes — affiliation bias, temporal logic bombs, and combined triggers. The 4-stage DSPy pipeline (ThreatClassifier → EvidenceExtractor → RiskScorer → QAValidator) is MIPROv2-compiled once and deployed anywhere. Driven by local OMLX.

Stack

DSPy · MIPROv2
OMLX / OpenAI-compatible vLLM
tslit_hw GPU telemetry (CUPTI/DCGM)
Command deck UI · stdlib HTTP
